# Application Screenshots — HACK-P309 Farmer Marketplace

This directory holds key application screenshots demonstrating the working features and workflows of **KisanSetu (HACK-P309 Farmer Marketplace)** as required by Section 6 & 8 of the Hackathon Submission Guidelines.

### Key Workflows & Views:
1. **Marketplace Catalog (`01-marketplace.png`)**: Produce discovery with search, category filtering, direct farmer contact, and price benchmark badges.
2. **Farmer Dashboard (`02-farmer-dashboard.png`)**: Inventory listing, bulk stock updates, order status management stepper (Requested -> Accepted -> Ready -> Completed), and earnings analytics.
3. **Buyer Order Tracking (`03-buyer-orders.png`)**: Active order lifecycle tracking, fulfillment choice (Farm Pickup / Delivery), and order history.
4. **Mandi Price Trends (`04-price-trends.png`)**: Visual market price trends, MSP benchmarks, and seasonal demand predictions for fair farmer pricing.
5. **Admin Moderation (`05-admin-moderation.png`)**: Quality inspection, flagging non-compliant listings, and audit trails.
